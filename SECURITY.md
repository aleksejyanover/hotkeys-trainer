# Security Policy / Политика безопасности

## Поддерживаемые версии / Supported versions

| Version | Supported |
|---|---|
| 1.x | ✅ |

## Сообщение об уязвимости / Reporting a vulnerability

Пожалуйста, **не публикуйте** уязвимости открыто в Issues.

Please **do not** report security vulnerabilities publicly in Issues.

Сообщите о проблеме одним из способов:
- через [GitHub Security Advisories](https://github.com/aleksejyanover/hotkeys-trainer/security/advisories/new) (предпочтительно)
- или создав приватный Issue с меткой `security`

Мы постараемся ответить в течение 72 часов.

We aim to respond within 72 hours.
