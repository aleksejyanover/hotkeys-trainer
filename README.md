Учебник, тренажёр и поиск горячих клавиш для **macOS** и **Windows** — с прогрессом, челленджами и тренажёром печати.
Desktop app for learning, practicing and searching keyboard shortcuts on **macOS** and **Windows** — with progress tracking, daily challenges and typing practice.

🌐 **Сайт с онлайн-версией:** <https://aleksejyanover.github.io/hotkeys-trainer/> — лендинг и полная веб-версия тренажёра прямо в браузере (прогресс сохраняется локально).
**Website with the web version:** a landing page and the full trainer running right in the browser.

## ✨ Возможности / Features

### Обучение / Learning
- 📚 **Учебник** — 83 карточки по 8 категориям: основные, одиночные клавиши, текст, браузер, файлы, полезные штуки, презентации, окна. Системные комбинации (Alt+Tab, Win+L…) помечены бейджем «Системное».
- ⌨️ **Одиночные клавиши** — для чего назначены стрелки ← → ↑ ↓, пробел, Enter, Tab, Esc, Backspace, Delete, Home/End, Page Up/Down, а также F, M и «/» — в тексте, списках, плеерах и презентациях.
- 📽️ **Презентации** — F5 (показ с начала), Shift+F5 (с текущего слайда), пробел/→ (следующий слайд), P/← (предыдущий), **B** (чёрный экран), **W** (белый экран), Esc (выход).
- 🎯 **Классический тренажёр** — нажимай комбинации и одиночные клавиши на реальной клавиатуре, приложение проверяет каждое нажатие.
- ⚡ **Спринт** — 60 секунд на максимум правильных нажатий в реальном времени.
- 🧩 **Квиз** — показано сочетание, выбери из четырёх вариантов, что оно делает — мышью или цифрами **1–4** с клавиатуры.
- ⌨️ **Тренажёр печати** — слепая печать с подсветкой ошибок, счётом WPM и рекордом.
- 🗺️ **Карта клавиш** — виртуальная клавиатура: видно, какие клавиши нажимать; клик по клавише показывает все сочетания с ней.

### Прогресс / Progress
- 📈 **Дашборд** — выучено X/Y, точность, попытки, серия дней, график за 7 дней, прогресс по категориям.
- 📅 **Ежедневный челлендж** — цель «5 новых + 10 повторений» и серия дней подряд.
- 🔥 **Слабые места** — сочетания, в которых чаще ошибаешься, с кнопкой «Тренировать».
- 🧠 **Умное повторение (SRS)** — сложные комбинации возвращаются чаще, лёгкие реже; в тренажёре сначала показываются созревшие для повторения.

### Удобство / Convenience
- 🔍 **Поиск** — по названию или самой комбинации («копировать», «Ctrl+C»).
- ⭐ **Заметки** — личные заметки к любому сочетанию + свои комбинации (попадают в учебник, карту и тренажёр).
- 💾 **Экспорт/импорт JSON** — перенос прогресса и заметок на другой компьютер.
- 🔊 **Звуки в тренажёре** — отклик при верном/неверном нажатии, тиканье на финише спринта (переключатель в шапке).
- 💡 **Совет дня** — случайное сочетание дня на вкладке тренажёра.
- 🌗 **Светлая/тёмная тема** в бирюзово-небесной гамме, переключатель **RU/EN** и **macOS/Windows** (платформа определяется автоматически).
- 💾 **Всё переживает перезапуск** — язык, тема, заметки, прогресс, а также последний режим и категория тренажёра, размер и положение окна.
- ⚡ **Быстрая навигация** — `Ctrl/Cmd+1…6` переключают вкладки; повторный запуск показывает уже открытое окно (один экземпляр приложения).

## 🚀 Запуск / Run

Требуется [Node.js](https://nodejs.org) 22.12+ (для менеджера версий: `nvm use`).

```bash
npm install
npm start
```

## 🧪 Тест / Test

Четыре части:

```bash
npm test
```

1. `npm run validate` — статическая проверка: данные (id, категории, токены клавиш, переводы), паритет RU/EN, перекрёстные связи `index.html` ↔ JS.
2. Smoke-тест в Electron: все вкладки, все 4 режима тренажёра, одиночные клавиши, Windows-платформа, экспорт/импорт — плюс прогон **всех комбинаций** через синтетические клавиатурные события (150 проверок).
3. E2E персистентности (`scripts/persistence-test.js`): фаза 1 меняет язык, заметку, своё сочетание и настройки тренажёра через UI и завершает приложение; фаза 2 (новый процесс) проверяет, что всё это пережило перезапуск.
4. E2E геометрии окна (`scripts/window-state-test.js`): окно меняет размер → закрывается → в новом запуске открывается с сохранёнными размером и позицией.

Готовые GitHub Actions-воркфлоу (CI и сборка дистрибутивов) лежат в [`.github/workflows-disabled/`](.github/workflows-disabled/README.md) — включаются одной командой (GitHub требует OAuth-scope `workflow` для записи в `.github/workflows/`).

## 📦 Сборка дистрибутива / Build

Локально:

```bash
npm run dist:mac    # → dist/*.dmg
npm run dist:win    # → dist/*.exe (на macOS — через Rosetta 2 + makensis)
```

Через GitHub Actions после включения воркфлоу из [`.github/workflows-disabled/`](.github/workflows-disabled/README.md) (Actions → **Build apps** → Run workflow) собираются **macOS .dmg** и **Windows .exe** автоматически — артефакты появятся в результатах запуска.

Иконка приложения генерируется скриптом (нужно только при изменении дизайна):

```bash
python3 build/make-icon.py   # → build/icon_1024.png
# далее iconutil собирает build/icon.icns (см. git-историю)
```

## 🌐 Сайт / Website

Статический сайт (лендинг + **веб-версия тренажёра**) публикуется через GitHub Pages из папки `docs/`:
<https://aleksejyanover.github.io/hotkeys-trainer/>

- Исходники лендинга — `site/`, они и `src/` собираются в `docs/` скриптом `npm run site`.
- Веб-версия — копия `src/` с `docs/app/web-shim.js`: браузерной заменой Electron-моста (экспорт — скачивание файла, импорт — выбор файла, платформа определяется по браузеру).
- `npm run validate` (часть `npm test`) проверяет, что `docs/` синхронен с `src/` и `site/` — после правок приложения обязательно пересобери сайт: `npm run site`.

A static site (landing page + full web version of the trainer) is published via GitHub Pages from `docs/`; `npm test` fails if it is out of sync with `src/`.

## 🗂 Структура проекта / Project structure

| Файл | Назначение |
|---|---|
| `main.js` | main process Electron (окно, меню, IPC, экспорт/импорт) |
| `preload.js` | мост между окном и main process |
| `src/index.html` | разметка приложения |
| `src/app.js` | вкладки: учебник, поиск, заметки, карта, прогресс |
| `src/trainer.js` | 4 режима тренажёра: классика, спринт, квиз, печать |
| `src/keys.js` | разбор комбинаций и сопоставление с событиями клавиатуры |
| `src/store.js` | состояние: прогресс, SRS, челлендж, тема/язык |
| `src/keyboard.js` | виртуальная клавиатура (mac/win) и чипы клавиш |
| `src/data.js` | каталог сочетаний для macOS/Windows |
| `src/typing.js` | тексты для тренажёра печати |
| `src/sfx.js` | звуки тренажёра (WebAudio) |
| `src/i18n.js` | строки интерфейса RU/EN |
| `src/styles.css` | стили, светлая/тёмная тема |
| `build/make-icon.py` | генерация иконки приложения |
| `scripts/validate.mjs` | статическая валидация проекта (`npm run validate`) |
| `scripts/build-site.mjs` | сборка сайта в `docs/` (`npm run site`) |
| `site/` | исходники лендинга (HTML/скриншоты) |
| `docs/` | сайт для GitHub Pages: лендинг + `app/` (веб-версия) |
| `scripts/screenshots.js` | скриншоты всех вкладок/тем для визуальной проверки |
| `scripts/persistence-test.js` | E2E: состояние переживает перезапуск приложения |
| `scripts/window-state-test.js` | E2E: размер/позиция окна переживают перезапуск |
| `smoke-test.js` | smoke-тест интерфейса (`npm test`) |

## 🛠 Технологии

- [Electron](https://www.electronjs.org) — кроссплатформенное десктопное приложение
- Vanilla HTML/CSS/JS (ES modules) — без фреймворков
- `localStorage` — прогресс, заметки и пользовательские сочетания хранятся локально
