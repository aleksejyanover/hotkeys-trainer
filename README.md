# ⌨️ Тренажёр сочетаний клавиш / Hotkeys Trainer

Учебник, тренажёр и поиск горячих клавиш для **macOS** и **Windows** — с прогрессом, челленджами и тренажёром печати.
Desktop app for learning, practicing and searching keyboard shortcuts on **macOS** and **Windows** — with progress tracking, daily challenges and typing practice.

## ✨ Возможности / Features

### Обучение / Learning
- 📚 **Учебник** — 50+ сочетаний по категориям: основные, текст, браузер, файлы, полезные штуки, окна. Системные комбинации (Alt+Tab, Win+L…) помечены бейджем «Системное».
- 🎯 **Классический тренажёр** — нажимай комбинации на реальной клавиатуре, приложение проверяет каждое нажатие.
- ⚡ **Спринт** — 60 секунд на максимум правильных нажатий в реальном времени.
- 🧩 **Квиз** — показано сочетание, выбери из четырёх вариантов, что оно делает.
- ⌨️ **Тренажёр печати** — слепая печать с подсветкой ошибок, счётом WPM и рекордом.
- 🗺️ **Карта клавиш** — виртуальная клавиатура: видно, какие клавиши нажимать; клик по клавише показывает все сочетания с ней.

### Прогресс / Progress
- 📈 **Дашборд** — выучено X/Y, точность, попытки, серия дней, график за 7 дней, прогресс по категориям.
- 📅 **Ежедневный челлендж** — цель «5 новых + 10 повторений» и серия дней подряд.
- 🔥 **Слабые места** — сочетания, в которых чаще ошибаешься, с кнопкой «Тренировать».
- 🧠 **Умное повторение (SRS)** — сложные комбинации возвращаются чаще, лёгкие реже; в тренажёре сначала показываются созревшие для повторения.

### Удобство / Convenience
- 🔍 **Поиск** — по названию или самой комбинации («копировать», «Ctrl+C»).
- ⭐ **Заметки** — личные заметки к любому сочетанию + свои комбинации (попадают в учебник, карту и тренажёр).
- 💾 **Экспорт/импорт JSON** — перенос прогресса и заметок на другой компьютер.
- 🔊 **Звуки в тренажёре** — отклик при верном/неверном нажатии, тиканье на финише спринта (переключатель в шапке).
- 💡 **Совет дня** — случайное сочетание дня на вкладке тренажёра.
- 🌗 **Светлая/тёмная тема** в бирюзово-небесной гамме, переключатель **RU/EN** и **macOS/Windows** (платформа определяется автоматически).

## 🚀 Запуск / Run

Требуется [Node.js](https://nodejs.org) 22.12+ (для менеджера версий: `nvm use`).

```bash
npm install
npm start
```

## 🧪 Тест / Test

Smoke-тест проверяет все вкладки и все 4 режима тренажёра:

```bash
npm test
```

## 📦 Сборка дистрибутива / Build

```bash
npm run dist        # macOS (.dmg) и Windows (.exe / NSIS)
npm run dist:mac    # только macOS
npm run dist:win    # только Windows
```

Готовые файлы появятся в папке `dist/`.

Иконка приложения генерируется скриптом (нужно только при изменении дизайна):

```bash
python3 build/make-icon.py   # → build/icon_1024.png
# далее iconutil собирает build/icon.icns (см. git-историю)
```

## 🗂 Структура проекта / Project structure

| Файл | Назначение |
|---|---|
| `main.js` | main process Electron (окно, меню, IPC, экспорт/импорт) |
| `preload.js` | мост между окном и main process |
| `src/index.html` | разметка приложения |
| `src/app.js` | вкладки: учебник, поиск, заметки, карта, прогресс |
| `src/trainer.js` | 4 режима тренажёра: классика, спринт, квиз, печать |
| `src/store.js` | состояние: прогресс, SRS, челлендж, тема/язык |
| `src/keyboard.js` | виртуальная клавиатура (mac/win) и чипы клавиш |
| `src/data.js` | каталог сочетаний для macOS/Windows |
| `src/typing.js` | тексты для тренажёра печати |
| `src/sfx.js` | звуки тренажёра (WebAudio) |
| `src/i18n.js` | строки интерфейса RU/EN |
| `src/styles.css` | стили, светлая/тёмная тема |
| `build/make-icon.py` | генерация иконки приложения |
| `smoke-test.js` | smoke-тест интерфейса (`npm test`) |

## 🛠 Технологии

- [Electron](https://www.electronjs.org) — кроссплатформенное десктопное приложение
- Vanilla HTML/CSS/JS (ES modules) — без фреймворков
- `localStorage` — прогресс, заметки и пользовательские сочетания хранятся локально
