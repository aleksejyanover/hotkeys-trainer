# ⌨️ Тренажёр сочетаний клавиш / Hotkeys Trainer

Учебник, тренажёр и поиск горячих клавиш для **macOS** и **Windows**.
Desktop app for learning, practicing and searching keyboard shortcuts on **macOS** and **Windows**.

## ✨ Возможности / Features

- 📚 **Учебник** — каталог сочетаний, сгруппированный по категориям: основные, текст, браузер, файлы, полезные штуки, окна. Отдельно показаны системные сочетания (Alt+Tab, Win+L и т.п.), которые перехватывает ОС.
- 🎯 **Тренажёр** — выбери категорию и нажимай комбинации на реальной клавиатуре: приложение проверяет правильность и считает очки, попытки и серию.
- 🔍 **Поиск** — найди действие или сочетание по названию («копировать», «Ctrl+C» и т.д.).
- ⭐ **Заметки** — личные заметки к любому сочетанию и свои пользовательские комбинации, которые тоже попадают в учебник и тренажёр.
- 🌐 **Русский / English** — переключение языка интерфейса.
- 💻 **macOS и Windows** — платформа определяется автоматически, переключатель в шапке позволяет посмотреть сочетания для другой ОС.

## 🚀 Запуск / Run

Требуется [Node.js](https://nodejs.org) 22.12+ (для менеджера версий: `nvm use`).

```bash
npm install
npm start
```

## 🧪 Тест / Test

Smoke-тест проверяет вкладки, поиск, тренажёр, заметки и переключение языка/платформы:

```bash
npm test
```

## 📦 Сборка дистрибутива / Build

```bash
# macOS (.dmg) и Windows (.exe / NSIS)
npm run dist

# только macOS
npm run dist:mac

# только Windows
npm run dist:win
```

Готовые файлы появятся в папке `dist/`.

## 🗂 Структура проекта / Project structure

| Файл | Назначение |
|---|---|
| `main.js` | main process Electron (окно, меню, IPC) |
| `preload.js` | мост между окном и main process |
| `src/index.html` | разметка приложения |
| `src/app.js` | логика: учебник, тренажёр, поиск, заметки |
| `src/data.js` | каталог сочетаний для macOS/Windows |
| `src/i18n.js` | строки интерфейса RU/EN |
| `src/styles.css` | стили |
| `smoke-test.js` | smoke-тест интерфейса (`npm test`) |

## 🛠 Технологии

- [Electron](https://www.electronjs.org) — кроссплатформенное десктопное приложение
- Vanilla HTML/CSS/JS (ES modules) — без фреймворков
- `localStorage` — заметки и пользовательские сочетания хранятся локально
